# CODTECH Internship Task-2

## Predictive Analysis using Machine Learning

This project builds a Machine Learning model to predict passenger survival using the Titanic dataset.

## Dataset

Titanic Survival Dataset

## Steps Performed

* Data loading
* Data preprocessing
* Feature selection
* Train-test split
* Logistic Regression model training
* Model evaluation

## Result

The Logistic Regression model predicts passenger survival using features such as passenger class, age, sex, and fare.

* Python
* Pandas
